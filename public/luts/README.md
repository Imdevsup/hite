# LUT catalog

Drop `.cube` files here — the build-registry script auto-registers each as a stable catalog entry. Naming convention: `{name}.cube`, lowercased, dash-separated.

Ship-in packs:
- **Lutify Free 100+** — drop-in
- **IWLTBAP 325+** — drop-in, filter down to ~200 keepers
- **Color Grading Central Sample** — hero keepers only

At launch, aim for ~300 production-grade LUTs after filtering. Every LUT auto-becomes a `lut-*` registry entry.
