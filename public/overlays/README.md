# Overlay asset catalog

Transparent WebMs and PNGs referenced by `engine: overlay-asset` registry entries.

**Format**: VP9 alpha WebM (`libvpx-vp9 -pix_fmt yuva420p -auto-alt-ref 0`) for motion, PNG for stills.

**Launch targets**:
- Skull (motion, 3s loop)
- Lightning (motion, 0.8s one-shot)
- Light leaks × 12 (motion)
- RGB split banner × 4
- Scan lines (png)
- CRT bezel (png)
- Film burn (motion)
- Fire (motion)
- Smoke (motion)
