# SFX

Short, tame sound effects referenced by `@/lib/sounds`.

- `tick.wav` — 18ms soft click. Grid snap, window dock.
- `genie-open.wav` — 140ms reverse whoosh. Window genie-open.
- `genie-close.wav` — 140ms forward whoosh. Window genie-close.
- `export-done.wav` — 400ms soft chime. Render succeeded.
- `playhead.wav` — 12ms pluck. Optional on scrub (off by default).

Record at 44.1k/16 mono. All under 500ms. Nothing jarring — these are ambient.
